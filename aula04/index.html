Principais Formatações

Semântico vs. Não Semântico


Negrito / Destaque

Aqui temos texto em negrito semântico. Hoje usamos a tag [strong], antes era tag [b].

Itálico / Ênfase

Aqui temos texto em itálico semântico. Hoje usamos a tag [em], antes era tag [i].

Marcado

Aqui temos texto marcado. Também temos aqui, usando a tag [mark], junto de "background-color: cadetblue".

Big / Small

Antes tinhamos a tag [big] que agora é deprecated Hoje só temos a tag [small] que deixa texto pequeno.

Deletado / Riscado

Agora temos o texto deletado, que usa a tag [del]; Porém antes tinhamos o riscado, que usava a tag [S].

Inserido / Sublinhado

agora isso se chama inserted e usa a tag [ins]; Mas na forma não semântica isso se chamava sublinhado e usava a tag [u].

Texto Sobrescrito

Estritamente semântica, essa aqui se chama texto sobrescrito e usa a tag [sup].

Texto Subscrito

Temos também essa tag [sub], para texto subscrito.

Trecho de Código

Para mostrar códigos completos, podemos usar... 

        essa-tag{ 
            nome='[pre] junto de [code]';
        }
para trechos de código.

Endereço

Olha
esta tag [address]
para endereços.

Code

Mais simples que aquela anterior, podemos usar também apenas a tag [code]. para código in-line.

Citações

Temos uma tag para citações;

"Temos uma tag para citações!"

...e ela se chama [cite].

Abreviações

Ou podemos abreviar usando [abbr]. Só buscadores vêem tudo.
